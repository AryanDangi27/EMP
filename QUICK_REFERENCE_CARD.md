## ✅ Required Fields Checklist

**Must Fill These 6 Fields:**

- [ ] **Full Name** - Patient's legal name
- [ ] **Email** - Contact email
- [ ] **Date of Birth** - Birth date
- [ ] **Gender** - Select from dropdown
- [ ] **Blood Group** - Select from dropdown
- [ ] **Emergency Contact 1** - Phone number

**Then click "Issue EMP Certificate"**

## 💡 Pro Tips

| Tip | Action |
|-----|--------|
| **Verify Everything** | Ask patient to confirm details |
| **Use Checkboxes** | Click boxes for common items |
| **Add Custom Items** | Type → Click "Add" if not listed |

| **Medical History** | Include surgeries and meds |
| **Review Modal** | Check everything before confirming |
| **Error? Cancel** | Click Cancel in modal to fix |

## 🆘 Need Help? Do This:

1. **Form won't submit?**
   - Check all 6 fields with RED *

2. **Custom entry not working?**
   - Type in field → Click + Add button
   - Or press ENTER key

3. **Can't find allergy in list?**
   - Scroll down to "Add custom allergy"
   - Type it there

4. **Made a mistake?**
   - In modal: Click "Cancel"
   - In form: Just edit and try again

5. **Still stuck?**
   - Contact IT: [phone]
   - Or Admin: [phone]
