# Hospital Staff - Enhanced EMP Form Quick Start

> **Welcome to the New Comprehensive EMP Issuance Form!**

This guide helps you navigate the enhanced form quickly.

---

## 📋 What Changed?

The EMP form now has **6 organized sections** instead of 3:

| # | Old | New |
|---|-----|-----|
| **1** | Basic Info | Patient Identity (5 fields) |
| **2** | Emergency Data | Emergency Contacts (2 fields) |
| **3** | Digital Link | - |
| - | - | **Allergies** (checkboxes + custom) |
| - | - | **Chronic Conditions** (checkboxes + custom) |
| - | - | **Medical History** (surgeries + meds) |
| - | - | **Digital Linking** (wallet - optional) |

---

## 🎯 Super Simple Workflow

### Step 1: Patient Identity (🔵 BLUE SECTION)
1. Enter patient's **full name**
2. Enter patient's **email**
3. Enter **date of birth**
4. Select **gender** from dropdown
5. Select **blood group** from dropdown

⏱️ *2-3 minutes*

### Step 2: Emergency Contacts (🔴 RED SECTION)
1. Enter primary emergency **contact 1** (phone number)
2. Optionally enter **contact 2** (phone number)

⏱️ *1 minute*

### Step 3: Allergies (🟠 AMBER SECTION)
1. **Check the box** for any known allergies
   - Common ones are listed (Penicillin, Latex, Peanuts, etc.)
2. If patient has an allergy NOT in the list:
   - Type it in the "Add custom allergy" field
   - Click the **+ Add** button (or press Enter)
   - It will appear in the list above

⏱️ *2-3 minutes*

### Step 4: Chronic Conditions (🟢 GREEN SECTION)
1. **Check the box** for any known conditions
   - Common ones are listed (Diabetes, Hypertension, Asthma, etc.)
2. If patient has a condition NOT in the list:
   - Type it in the "Add custom condition" field
   - Click the **+ Add** button (or press Enter)
   - It will appear in the list above

⏱️ *2-3 minutes*

### Step 5: Medical History (🟣 PURPLE SECTION)
1. Optional: List any **previous surgeries**
   - Example: "Appendectomy (2015), ACL Repair (2019)"
2. Optional: List any **current medications**
   - Example: "Metformin 500mg twice daily, Lisinopril 10mg"

⏱️ *1-2 minutes*

### Step 6: Digital Linking (🔵 BLUE SECTION - Optional)
1. Patient wallet address (optional)
   - Usually starts with "0x"
   - Leave blank if not available
   - System will auto-generate an ID

⏱️ *30 seconds*

### Step 7: Submit
- Click the big blue **"Issue EMP Certificate"** button

⏱️ *Total time: 10-15 minutes per patient*

## 🆕 New Features Explained

### Feature 1: Checkbox Selections

**Allergies & Chronic Conditions now use checkboxes!**

```
OLD WAY: "Type everything in a text box"
├─ Hard to read
├─ Inconsistent
└─ Easy to miss items

NEW WAY: "Check boxes for known items"
├─ Professional
├─ Consistent
├─ Complete
└─ Easy to review
```

**How to use:**
1. Look at the list of common items
2. Click the checkbox next to any that apply
3. Item will be marked with a checkmark ✓

### Feature 2: Add Custom Items

**Found an allergy or condition not in the list?**

```
[Type allergy or condition here] [+ Add Button]
```

Steps:
1. Type the item name in the text box
2. Click **+ Add** or press **Enter**
3. Item is added to the selected list
4. Can remove later by clicking the **X** button

### Feature 3: Multiple Emergency Contacts

**Old:** One emergency contact
**New:** Two emergency contacts (1 required, 1 optional)

Why? In emergencies, having a backup contact saves lives!

### Feature 4: Medical History Tracking

**New fields for important medical info:**
- **Previous Surgeries** - "Appendectomy (2015), ACL Repair (2019)"
- **Current Medications** - "Metformin 500mg twice daily"

This helps emergency responders understand the patient's medical background.

## 💡 Pro Tips

### Tip 1: Verify Everything
Before clicking "Issue":
- Ask patient to confirm blood group
- Ask about ALL allergies (not just common ones)
- Get phone numbers right (people won't miss calls)
- Double-check medications

### Tip 2: Use Custom Fields
If allergy/condition not in list → Type it!
- Never force it
- Never leave it out
- Just add it as custom

### Tip 3: Complete Medical History
Even "optional" fields are important:
- Previous surgeries help doctors understand patient
- Current medications could be life-saving in emergency
- Takes just 1 minute, saves lives

### Tip 4: Two Emergency Contacts
If possible, get both contacts:
- Contact 1: Person most likely to answer
- Contact 2: Backup (family member, friend)
- One call, then the other

### Tip 5: Review Before Confirming
After clicking "Issue EMP Certificate":
- Modal appears with summary
- Check patient name is correct
- Check allergy count
- Check condition count
- If wrong → Click "Cancel" and fix
- If correct → Click "Confirm"

## ⚠️ Common Issues & Fixes

### Issue 1: "Can't submit form"
**Reason:** Missing a required field (has red *)
**Fix:** 
- Check all fields with red asterisk *
- Name, DOB, Gender, Blood Group, Contact 1

### Issue 2: "Where did my custom allergy go?"
**Reason:** Forgot to click + Add button
**Fix:**
- Type in the field
- Click **+ Add** button (or press Enter key)
- Will appear in the selected list

### Issue 3: "How do I remove something?"
**Reason:** Selected wrong item
**Fix:**
- Find the item in the list above
- Click the **X** button on it
- It will be removed

### Issue 4: "Can't find allergy in list"
**Reason:** Item is custom, not in common list
**Fix:**
- Scroll down to "Add custom allergy" field
- Type it there
- Click **+ Add**

### Issue 5: "Form keeps resetting"
**Reason:** Clicked "Issue Another EMP" button
**Fix:**
- That's intentional! 
- It resets form for the next patient
- Start fresh with new patient info

## 📞 Emergency Reference

### If Patient is in Severe Condition
1. **SKIP optional fields** - Go fast!
2. Fill only **required** fields (red *)
3. **Submit immediately**
4. Fill detailed info later if needed

### If You Make a Mistake
1. **Stop immediately**
2. Click **"Cancel"** in the confirmation modal
3. Fix the information
4. **Re-submit**
5. **Don't** accidentally confirm wrong data

### If Form Won't Load
1. Refresh the page
2. Clear browser cache
3. Try different browser
4. Contact IT support
