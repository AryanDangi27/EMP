## 🎬 How It Works

### User Journey
```
1. User arrives at /access-platform
   ↓ (Sees 4 beautiful role cards)
   ↓ Clicks "Hospital"

2. Redirects to /login
   ↓ (Split-screen with doctor animation)
   ↓ Enters any credentials & signs in

3. Lands on /hospital
   ↓ (Main menu with 5 options)
   ↓ Clicks "Issue EMP"

4. Goes to /hospital/issue-emp
   ↓ (Fills 8 patient fields)
   ↓ Clicks "Generate Certificate"

5. Sees beautiful certificate
   ↓ (QR code, Hospital badge, IPFS hash)
   ↓ Can download as PNG

6. QR Code scans to /verify-emp/[empId]
   ↓ (Public verification page)
   ↓ Selects role (Patient/Emergency/Doctor)

7. Views role-specific data
   ↓ (Different info for each role)
   ↓ Complete security workflow
```
